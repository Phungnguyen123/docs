# Fonts

Brand font for the motion-graphics pipeline.

- **Poppins** (`poppins/`) — SIL Open Font License 1.1 (see `poppins/OFL.txt`).
  Static weights used by the title cards / lower-thirds / overlays:
  Regular (400), Medium (500), SemiBold (600), Bold (700).
  Source: https://github.com/google/fonts/tree/main/ofl/poppins

These are the typefaces required by the project design system (Poppins for all
text). The graphics generators load them by absolute path from `.fonts/poppins/`.
